## 一、主题概述

本阶段科研轮转的主题是**大模型强化学习与搜索增强推理**。相关学习内容主要围绕三条主线展开：一是以 PPO 为代表的经典策略优化方法，二是以 GRPO 为代表的面向大模型后训练的高效强化学习变体，三是以 Search-R1 为代表的搜索增强推理框架。若从方法演化的角度观察，这三部分内容对应了三个逐步展开的问题：

1. 在强化学习中，如何在提升策略性能的同时保持训练稳定；
2. 当训练对象变为大语言模型后，如何降低强化学习过程中的资源消耗与工程复杂度；
3. 当模型需要与外部信息环境交互时，如何将搜索行为纳入推理与优化过程。

因此，本阶段工作的重点并非形成具体研究结果，而是建立一条相对清晰的知识脉络：从经典策略优化出发，理解其在大模型场景中的改造逻辑，再进一步把这些方法放入搜索增强推理的框架中考察其作用与局限。

## 二、PPO：经典策略优化的稳定性逻辑

### 1. 问题背景

PPO（Proximal Policy Optimization）是强化学习中最具代表性的策略梯度方法之一。在策略梯度框架中，策略更新的核心目标是增大高优势动作的概率，同时减小低优势动作的概率。然而，如果直接在同一批采样轨迹上做多轮梯度更新，策略很容易发生过大的偏移，从而破坏训练稳定性。

PPO 的核心贡献正在于：它并不追求“无约束地提高策略”，而是在**性能提升**与**更新幅度控制**之间建立平衡。这一平衡使其成为后续大模型强化学习方法的重要起点。

### 2. 核心思想

PPO 用概率比值来衡量新旧策略之间的变化：

$$
r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t\mid s_t)}.
$$

在此基础上，PPO 引入 clipped surrogate objective：

$$
L^{\mathrm{CLIP}}(\theta)=\hat{\mathbb E}_t\Big[\min\big(r_t(\theta)\hat A_t,\;\mathrm{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t\big)\Big].
$$

这一目标的作用可以概括为两点：

- 当策略更新幅度较小时，目标函数与普通策略梯度近似一致；
- 当更新幅度超过阈值时，裁剪机制抑制继续偏离，从而避免一次更新走得过远。

因此，PPO 能够在同一批样本上进行多轮 minibatch 更新，而不会像无约束策略梯度那样频繁出现更新失控的问题。

### 3. 方法意义

结合论文内容，可以将 PPO 的意义概括为以下几点：

- 它延续了策略梯度方法直接优化策略的优点；
- 它继承了信赖域方法重视稳定性的思想，但在实现上更简单；
- 它使“多轮更新同一批样本”成为可行策略，从而提高样本利用率；
- 它为后续大模型强化学习提供了一个结构清晰、工程上可扩展的优化模板。

此外，PPO 在实际训练中通常并不是独立使用单一策略损失，而是与 value loss、entropy bonus 等部分共同构成完整目标。这意味着对 PPO 的理解不能只停留在公式层面，而必须把它看成一个由**策略优化、价值估计、探索控制与超参数组织**共同构成的训练系统。

### 4. 局限与引申

尽管 PPO 已经较好地兼顾了性能与稳定性，但在大语言模型场景中，它仍然存在明显成本问题。尤其是在 actor-critic 结构下，训练往往需要额外的 value model；而在模型规模很大时，这会带来显著的显存、计算与工程负担。这一问题正是后续 GRPO 出现的重要背景。

## 三、GRPO：面向大模型后训练的高效强化学习变体

### 1. 从 PPO 到 GRPO 的问题转移

如果说 PPO 主要解决的是“策略更新如何保持稳定”，那么 GRPO 进一步关注的问题则是：**当强化学习被用于大模型后训练时，如何降低训练资源消耗并简化实现结构。**

DeepSeekMath 中提出的 GRPO（Group Relative Policy Optimization）延续了 PPO 的基本思路，但在优势估计与训练结构上做了重要改造。其关键变化在于：不再显式依赖一个独立的 value model，而是通过同一问题下多个候选输出之间的组内相对得分来构造基线与优势。

### 2. GRPO 的核心机制

在论文给出的设定中，针对同一输入问题，模型会采样一组输出，并基于奖励模型或规则奖励得到组内分数，再据此进行相对归一化。直观地看，GRPO 不再追求“每个 token 都有一个由 critic 估计出的价值”，而是改为回答这样的问题：**在同一问题的多个候选答案中，当前输出相对其他候选到底表现如何。**

这种改造带来的直接结果是：

- 减少了对独立 value model 的依赖；
- 降低了显存和计算成本；
- 使训练流程更贴近当前大模型后训练中对效率和工程复杂度的要求。

从方法定位上看，GRPO 并不是对 PPO 的完全替代，而是在大模型场景下对 PPO 的一次结构性简化与重组。

### 3. DeepSeekMath 提供的统一视角

DeepSeekMath 的一个重要贡献，不仅在于提出 GRPO，还在于尝试用统一范式理解 SFT、RFT、DPO、PPO 与 GRPO。按照论文中的归纳，这些方法可以从以下三个维度进行比较：

- **数据来源**：训练样本来自监督数据、离线采样还是在线采样；
- **奖励函数**：使用规则奖励、偏好数据还是奖励模型；
- **梯度系数**：不同算法如何根据奖励信号调整对样本的强化或惩罚强度。

这一统一视角的重要性在于，它将原本看似零散的方法放回到同一问题框架中：本质上，这些方法都在回答“模型应该在什么数据上、按照什么信号、以多大强度被更新”。因此，GRPO 的意义不仅在于“去掉了 value model”，还在于它进一步说明：大模型强化学习的发展并不是简单沿用传统 RL，而是在训练对象变化之后重新组织整个优化链条。

### 4. 对 RL 作用边界的进一步认识

根据论文中的实验分析，至少在其报告的设置中，可以观察到若干重要现象：

- 在线方法通常优于离线方法；
- 过程监督在某些场景下优于仅结果监督；
- 迭代式 RL 能继续带来收益；
- RL 对 Maj@K 的改善往往更显著，而对 Pass@K 的改善不一定同样明显。

这些结果提示出一个关键认识：在大模型场景中，强化学习的作用很多时候并不是凭空创造能力，而更像是对已有能力进行重新分布、重新对齐和重新放大。换言之，RL 的一个重要功能是**改善模型在给定任务分布中的输出组织方式**，而不仅仅是扩展其能力上限。

### 5. 从 GRPO 引出的工程与研究问题

GRPO 进一步暴露了大模型强化学习中的几个基础问题：

- 奖励信号是否可靠；
- 奖励模型是否具有足够泛化性；
- 过程监督与结果监督分别在哪些任务中更有效；
- 高效训练与稳定训练之间如何权衡。

这些问题说明，大模型强化学习并不是单纯的“优化算法问题”，而是同时涉及训练资源、奖励质量、样本组织和工程可实现性的问题。

## 四、Search-R1：从策略优化走向搜索增强推理

### 1. 问题的进一步扩展

PPO 与 GRPO 主要关注的是策略本身如何优化，而 Search-R1 将问题进一步扩展为：**当模型需要外部信息时，如何在推理过程中主动调用搜索，并将搜索行为纳入强化学习优化目标。**

这一变化意味着研究重点不再只是“如何生成更好的答案”，而是进一步转向“如何在推理过程中决定是否搜索、搜索什么、以及如何根据搜索结果继续推理”。相较于传统的单轮 RAG，Search-R1 更强调推理过程与搜索行为之间的耦合。

### 2. Search-R1 的结构化推理框架

根据论文中的系统设计，Search-R1 允许模型以如下方式组织生成过程：

- `<think>`：表示当前阶段的推理内容；
- `<search>`：表示主动发起的检索请求；
- `<information>`：表示外部搜索返回的信息；
- `<answer>`：表示最终答案。

这种结构并不只是模板设计，而是将推理显式拆分为多个可交互阶段，使模型能够在多轮过程中完成如下循环：

1. 对当前问题进行局部推理；
2. 判断是否存在知识缺口；
3. 生成检索查询；
4. 读取返回信息；
5. 基于新信息继续推理；
6. 在必要时重复上述过程，直到形成最终答案。

因此，Search-R1 所处理的对象已经不再是纯粹的“文本生成轨迹”，而是**带有环境交互的推理轨迹**。

### 3. PPO / GRPO 在搜索场景中的延续

Search-R1 的一个重要特点，是它并没有抛弃 PPO 和 GRPO，而是在论文设定下展示了搜索增强推理与这两类 RL 方法结合的可能性。这说明搜索增强推理并不是对先前方法的替换，而是将先前的策略优化方法嵌入到了一个更复杂的环境交互场景中。

在这一框架下，策略优化面对的新问题包括：

- 搜索调用是离散动作，无法直接用普通监督学习端到端优化；
- 推理序列中同时包含模型生成 token 与检索返回 token；
- 多轮检索会显著改变上下文结构与响应长度；
- 奖励需要覆盖“最终回答是否正确”，同时尽量不引入过强的人工过程约束。

### 4. Retrieved Token Masking 的工程意义

Search-R1 中一个非常关键的工程设计是 **retrieved token loss masking**。按照论文中的描述，RL 损失只作用于模型自行生成的 token，而不作用于外部检索返回的 token。其意义在于，检索结果来自环境，不应被当作模型自己的生成行为来优化。

这一点表面上是细节，实际上非常关键。若不加区分地对整段 rollout 施加损失，训练过程就会把环境提供的信息也视作模型应承担责任的部分，从而引入不必要的优化噪声。通过 masking，Search-R1 更清楚地划定了训练边界：

- 模型负责的是**搜索决策**与**信息整合后的推理行为**；
- 环境负责的是**检索返回内容本身**。

这一设计体现出搜索增强推理训练中一个非常重要的工程原则，即必须明确区分“模型输出”与“环境反馈”。

### 5. 奖励设计：简单结果奖励为何仍然有效

Search-R1 采用了相对简单的 outcome-based reward，而没有使用复杂的过程奖励。论文结果表明，在其任务设定中，这种简单奖励仍然足以驱动模型学习多轮搜索与推理行为。这个现象说明，在某些场景下，只要任务结构与轨迹组织足够合理，最终结果奖励也可以支持模型学会何时搜索、如何逐步逼近答案。

这与 DeepSeek-R1 / DeepSeekMath 中一些现象形成了呼应：复杂推理能力未必一定依赖复杂奖励，关键还在于轨迹结构、训练数据组织和优化过程是否能够把正确行为稳定放大。

### 6. Search-R1 提供的进一步认识

Search-R1 的实验与案例分析揭示了搜索增强推理中的若干关键特征：

- GRPO 收敛通常更快，但 PPO 在训练稳定性上更占优势；
- 指令模型往往起点更高、收敛更快，但基础模型经过 RL 后也能逐步逼近；
- 响应长度与有效搜索次数会随着训练发生显著变化；
- 检索 passage 数量、GRPO 组大小等超参数会直接影响训练行为；
- 搜索增强推理虽然能够支持迭代检索、自我验证和辅助查询生成，但仍可能因为错误问题分解、检索噪声或误导性信息而失败。

因此，搜索并不是天然可靠的信息增强器。搜索增强推理的有效性，不仅取决于模型会不会搜索，还取决于检索质量、问题分解能力、信息整合能力以及训练目标是否合理。

## 七、阶段性总结

从知识脉络上看，本阶段形成的核心认识可以概括如下：

1. **PPO** 解决的是策略优化中的稳定性问题，其关键在于通过裁剪目标限制更新幅度，从而提高样本利用率并保持训练可控。
2. **GRPO** 进一步回应了大模型后训练的实际需求，通过组内相对比较弱化对独立 value model 的依赖，在一定程度上降低了资源消耗与工程复杂度。
3. **Search-R1** 将强化学习从纯策略优化推进到与外部环境交互的推理场景中，使“何时搜索、搜索什么、如何利用检索结果继续推理”成为可优化对象。

若进一步抽象，本阶段学习内容实际对应的是一个连续的发展脉络：

$$
\text{稳定策略优化} \;\longrightarrow\; \text{面向大模型的高效 RL} \;\longrightarrow\; \text{搜索增强的交互式推理}.
$$

这条脉络说明，大模型强化学习的发展并不是孤立地提出一个又一个新方法，而是在不同阶段持续回答同一个核心问题：当训练对象、任务结构与环境交互方式发生变化时，策略优化应当如何随之调整。

从后续工作角度看，值得继续深入的问题主要包括：

- 强化学习究竟在多大程度上改变了模型能力边界，或只是重新组织了输出分布；
- 过程监督与结果监督分别适合什么类型的推理任务；
- 搜索策略设计与最终推理质量之间究竟是怎样的关系；
- 搜索增强推理中的奖励设计、环境交互与训练稳定性如何进一步统一。

这些问题构成了本阶段之后继续推进学习与研究的主要方向。
